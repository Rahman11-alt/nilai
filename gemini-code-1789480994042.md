# 🎓 Aplikasi Administrasi Siswa Berbasis Web

Aplikasi Sistem Informasi Administrasi Siswa yang modern, responsif, dan terintegrasi langsung dengan **Google Sheets** sebagai database permanen melalui **Google Apps Script**.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-active-brightgreen.svg)

---

## 🌟 Fitur Utama

- 📊 **Dashboard Realtime**: Ringkasan jumlah siswa, siswa laki-laki, perempuan, dan total kelas.
- ➕ **Tambah Data Siswa**: Input data lengkap siswa dengan validasi form.
- ✏️ **Edit Data Siswa**: Perbarui data siswa kapan saja dan perubahan otomatis disimpan.
- 🗑️ **Hapus Data Permanen**: Dialog konfirmasi sebelum hapus data dari Google Sheets.
- 🔍 **Pencarian & Filter**: Cari cepat berdasarkan Nama, NISN, NIS, Ortu, serta Filter per Kelas.
- 📥 **Import Excel Batch**: Unduh template Excel & import data siswa sekaligus.
- 📤 **Export ke Excel**: Unduh seluruh daftar siswa ke file `.xlsx`.
- 💾 **Penyimpanan Permanen**: Seluruh data tersimpan aman di Google Sheets dan tidak hilang walau browser ditutup.
- 📱 **Responsif & Modern**: Tampilan bersih, intuitif, dan nyaman digunakan dari Smartphone maupun Desktop.

---

## 🛠️ Teknologi yang Digunakan

- **Frontend**: HTML5, CSS3, JavaScript (ES6+), FontAwesome Icons, SheetJS.
- **Backend**: Google Apps Script (GAS).
- **Database**: Google Sheets.
- **Hosting**: GitHub Pages.
